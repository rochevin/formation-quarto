Callouts

Callouts are useful for highlighting important information.

How to do it

::: {.callout-note}
## A note

This is some additional information.
:::

What it does

NoteA note

This is some additional information.

Callout types

Tip

Tip: Use callouts for useful suggestions.

Warning

Warning: This deserves attention.

Important

Important: Don’t forget this!

Caution

Caution: Something potentially problematic.

Note

Note: Just some additional context.
